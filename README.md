# Ανίχνευση ανοίγματος παραθύρου με μαγνητόμετρο (Raspberry Pi + Sense HAT)

*Window opening detection with a magnetometer: a Raspberry Pi with a Sense HAT on the fixed frame and a permanent magnet on the moving sash estimate how far a window is open (cm and %).*

Πτυχιακή εργασία: *Σχεδιασμός και Υλοποίηση Μηχανισμού Ανίχνευσης Ανοίγματος Παραθύρου σε Περιβάλλον Smart Campus*.
Γεώργιος Σάκκος, Τμήμα Πληροφορικής, Σχολή Πληροφορικής και Τηλεματικής, Χαροκόπειο Πανεπιστήμιο (2026).

Το σύστημα εκτιμά **πόσο** ανοιχτό είναι ένα παράθυρο, και όχι μόνο αν είναι ανοιχτό ή κλειστό. Ένα μαγνητόμετρο στο σταθερό κούφωμα μετράει το πεδίο ενός μόνιμου μαγνήτη στερεωμένου στο κινούμενο φύλλο. Δεν χρειάζεται τροφοδοσία στο φύλλο, οπτική επαφή ή επιφάνειες-στόχους.

![Αρχιτεκτονική του συστήματος](figures/eikona_2_2_arxitektoniki.png)

## Πώς λειτουργεί

1. **Υπόβαθρο:** με τον μαγνήτη απομακρυσμένο μετριέται το διάνυσμα του πεδίου του χώρου, B₀ (γήινο πεδίο και σταθερές διαταραχές).
2. **Μεταβολή πεδίου:** σε κάθε μέτρηση υπολογίζεται Δ = |B − B₀| με **διανύσματα**. Έτσι απομονώνεται το πεδίο του μαγνήτη ανεξάρτητα από τον προσανατολισμό του αισθητήρα. Μετά από μετακίνηση του Pi αρκεί νέα μέτρηση του υποβάθρου, όχι νέα βαθμονόμηση.
3. **Βαθμονόμηση:** μετράται το Δ σε γνωστά ανοίγματα (περίπου ανά 5 cm) και προσαρμόζονται τρία μοντέλα με σταθμισμένα ελάχιστα τετράγωνα:
   - δίπολο `a/(x+x0)^3 + c`
   - νόμος δύναμης `a/(x+x0)^n + c`
   - εκθετικό `a·exp(−bx) + c`
4. **Επιλογή μοντέλου:** χρησιμοποιείται το μοντέλο με το μικρότερο σφάλμα απόστασης **leave-one-out** (cm), δηλαδή αυτό που προβλέπει καλύτερα σημεία που δεν είδε κατά την προσαρμογή.
5. **Ανίχνευση:** οι μετρήσεις εξομαλύνονται με εκθετικό κινητό μέσο (σταθερά χρόνου περίπου 2 s) και το αντίστροφο μοντέλο δίνει το άνοιγμα σε cm και %.
6. **Ολίσθηση:** η θερμοκρασία του αισθητήρα μετακινεί το υπόβαθρο (περίπου 0,5 µT/°C). Όταν το παράθυρο μένει 5 λεπτά πλήρως ανοιχτό, το υπόβαθρο διορθώνεται αυτόματα, χωρίς απομάκρυνση του μαγνήτη.

## Υλικό

- Raspberry Pi 5 (8 GB), Raspberry Pi OS 64-bit (Debian 12 «Bookworm»), Python 3.11
- Sense HAT v2 (μαγνητόμετρο LSM9DS1)
- Μόνιμος μαγνήτης νεοδυμίου στο κινούμενο φύλλο, στο ύψος του Sense HAT

## Αρχεία

| Αρχείο | Ρόλος |
|---|---|
| `app.py` | Εφαρμογή web (Streamlit): ζωντανή ένδειξη, βαθμονόμηση, re-baseline, καταγραφές |
| `window_detector.py` | Ανάγνωση αισθητήρα, βαθμονόμηση, ανίχνευση, καταγραφή, αυτόματο re-baseline, μενού τερματικού |
| `models.py` | Μοντέλα, σταθμισμένη προσαρμογή, leave-one-out, αντιστροφή (χωρίς εξάρτηση από υλικό) |
| `compare_models.py` | Ανάλυση: σύγκριση μοντέλων (lmfit, AIC/BIC), γράφημα και αναφορά |
| `window-detector.service` | Υπηρεσία systemd για αυτόματη εκκίνηση της ανίχνευσης |
| `README.txt` | Σύντομες οδηγίες χρήσης στο Pi |

Οι φάκελοι `calibrations/` (βαθμονομήσεις, JSON και CSV) και `logs/` (καταγραφές, CSV) δημιουργούνται αυτόματα.

## Εγκατάσταση (μία φορά, στο Raspberry Pi)

```bash
python3 -m venv --system-site-packages ~/wd-venv
~/wd-venv/bin/pip install streamlit "numpy<2"
```

Το `--system-site-packages` δίνει πρόσβαση στις βιβλιοθήκες `sense_hat` και SciPy του συστήματος. Το `numpy<2` χρειάζεται για συμβατότητα με το SciPy του Raspberry Pi OS.

Για τη σύγκριση μοντέλων (προαιρετικά):

```bash
~/wd-venv/bin/pip install lmfit matplotlib "numpy<2"
```

## Χρήση

**Εφαρμογή web:**

```bash
cd ~/Desktop/rasberry
~/wd-venv/bin/streamlit run app.py
```

Ανοίγει στο `http://localhost:8501`, ή στο `http://raspberrypi.local:8501` από άλλη συσκευή στο ίδιο δίκτυο.

![Σελίδα Live](figures/eikona_3_4b_live.png)

**Τερματικό:**

```bash
python3 window_detector.py                   # μενού
python3 window_detector.py --detect ΟΝΟΜΑ    # ανίχνευση με συγκεκριμένη βαθμονόμηση
python3 window_detector.py --detect latest   # ανίχνευση με την πιο πρόσφατη βαθμονόμηση
```

**Αυτόματη εκκίνηση (systemd):**

```bash
sudo cp window-detector.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now window-detector
```

Η εφαρμογή και η υπηρεσία διαβάζουν τον ίδιο αισθητήρα, άρα δεν τρέχουν ταυτόχρονα. Πριν ανοίξεις την εφαρμογή δώσε `sudo systemctl stop window-detector`, και μετά `start`.

**Σύγκριση μοντέλων:**

```bash
~/wd-venv/bin/python compare_models.py calibrations/ΟΝΟΜΑ.json
```

## Συμβουλές βαθμονόμησης

- Άφησε το σύστημα να λειτουργήσει 20–30 λεπτά πριν από τη βαθμονόμηση, ώστε να σταθεροποιηθεί η θερμοκρασία.
- Τοποθέτησε τον μαγνήτη στο ύψος του Sense HAT, ώστε να κινείται προς τον αισθητήρα και μακριά του.
- Μέγιστο άνοιγμα περίπου 35–40 cm, με σημεία ανά 5 cm. Για το αυτόματο re-baseline, το μέγιστο να είναι μερικά cm πριν από τη θέση «πλήρως ανοιχτό».
- Το υπόβαθρο (Re-baseline) μετριέται πάντα με τον μαγνήτη **απομακρυσμένο**.

## Αποτελέσματα (συρόμενο παράθυρο)

- Σφάλμα μικρότερο από 1 cm έως περίπου 25 cm.
- Έως περίπου 2 cm στα 35–40 cm με πρόσφατο υπόβαθρο.
- Θερμική ολίσθηση περίπου 0,5 µT/°C. Η επαναμέτρηση του υποβάθρου, χειροκίνητη ή αυτόματη, την αντισταθμίζει.
